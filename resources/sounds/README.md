# Alarm sounds

Both files are generated by `generate.py` in this directory. They are pure synthesized tones
(a two note chime and a single soft note) written with Python's standard `wave` module, 44.1 kHz,
16 bit, mono.

- `chime.wav`: block start, focus end, unconfirmed block and cutoff warnings.
- `soft.wav`: soft reminders, block ending soon and break end.

They were made for Cadence and are released under CC0 1.0 Universal (public domain dedication),
so they can be reused without attribution. Regenerate them with:

```sh
python resources/sounds/generate.py
```
